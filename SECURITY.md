# Security Policy

## Supported version

Security reports currently apply to the latest Fylert Beta release listed on the [Releases page](https://github.com/Fylert/fylert-desktop/releases).

## Report a vulnerability privately

Please email `support@fylert.com` with the subject `Fylert security report`.

Include only the information needed to understand and reproduce the issue:

- Fylert version
- operating system and version
- affected feature
- clear reproduction steps
- expected and observed behavior

Do not open a public Issue with vulnerability details. Do not attach confidential documents or paste their contents, file names, internal paths, personal data, credentials, or customer information. If a sample file is necessary, create a synthetic file containing no sensitive information and wait for a reply before sending it.

This repository is used for Beta downloads, release notes, and issue tracking. The Fylert application source code is not published here.
